# Règles comptables

Aucune règle ni code de compte n'est activé. Le CGNC, le plan comptable applicable, les schémas d'achats et fournisseurs, les justificatifs et l'avis 24 doivent être examinés dans leurs versions pertinentes et validés par un professionnel marocain avant l'implémentation de propositions. Le contrôle HT + TVA = TTC est une vérification arithmétique uniquement, pas une validation fiscale.
